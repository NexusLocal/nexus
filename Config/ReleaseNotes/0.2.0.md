# Nexus 0.2.0: WordPress, meet Nexus 🎉

Thank you for all the positive feedback on 0.1! This release brings what you asked for most. Nexus now runs WordPress as well as it runs Laravel. A new site, an import or a workspace takes one click.

## 🧱 WordPress, done right

- Nexus finds WordPress and Bedrock sites and gives them the right web rules on nginx and Apache.
- The Site screen shows the version, the database and the configuration. It sets up wp-config.php or a database for you.
- Multisite works, also on subdomains.
- `nexus wp` runs WP-CLI with the PHP version of the site.
- Change the URLs of a site to its Nexus URL in one click. Changed your mind? Undo it.
- Nexus warns when a plugin sends real mail. It can turn that plugin off for you.

## 📥 Import a WordPress site

Drop a backup on the Overview. Nexus reads exports of Local, Studio and Jetpack, `.wpress` files of All-in-One WP Migration and a folder with a dump. It makes the site, the database and a git repository. Then it changes the URLs. In the terminal: `nexus import`.

## ✨ A new site in one click

Laravel (with its starter kits), WordPress, Next.js, Nuxt, Vite and Astro. Nexus makes the folder, the database and a git repository. Then it opens the site over HTTPS. In the terminal: `nexus new`.

## 📬 A mail inbox for every site

Every mail that your sites send goes to the inbox of Nexus. No test mail ever reaches a real customer again. Each mail shows the site that sent it.

## 🌳 Better workspaces

- Each git worktree of a WordPress site gets its own database and domain.
- A Node.js app gets its own database in each workspace.
- New: start a workspace with an empty database. Your migrations and seeders run from zero, and an agent never sees customer data.

## 🛠 And more

- The first run asks what you build and installs the right versions.
- The Site screen of a Laravel site shows its databases.
- A failed action shows its details. Send a report to us with one click.
- Anonymous crash reports. Turn them off in Settings > Advanced.
- After a crash or an update, nexusd starts your services again by itself.
