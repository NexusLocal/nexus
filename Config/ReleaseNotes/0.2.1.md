# Nexus 0.2.1: Apache sites that force HTTPS

A small update with fixes for Apache sites and for the mail service.

## 🔒 Apache sites with an HTTPS rule work

Many WordPress sites have a `.htaccess` rule that sends each request to HTTPS. Behind Nexus such a site sent the browser to the same address again and again. nginx now sends the requests of an Apache site to Apache over TLS. So these rules see HTTPS as in production, and the site opens.

A request on the HTTP port of an Apache site now goes to HTTPS first. Sites on nginx stay as they are.

## 🛠 And more

- The mail service frees its port before it stops. A port change or the removal of the mail package no longer finds the port in use.
