# Nexus 0.7.2: pgvector, gmp and memcached

## 🐘 pgvector

PostgreSQL 15 to 19 have pgvector 0.8.7, for the search in embeddings. The package update comes by itself. Then run `CREATE EXTENSION vector` in your database.

## 🧩 gmp and memcached

PHP 8.2 to 8.5 get two more extensions with their next package update.

- **gmp** calculates with whole numbers of any size. It is on, unless you changed a switch of that PHP version before.
- **memcached** connects to a memcached server. It is off until you turn it on, and it needs igbinary.

## 🛠 Fixes

- **"Replace only the tables" with a file of pg_dump -Fc.** A foreign key or a view of another table kept an old table in place, and the rows of the dump came next to the old rows. Nexus now checks the dump first. When something else uses a table of the dump, the import stops and changes nothing. The message names what uses the table.
- **No false error for a shared extension or type.** Such an import also ended with "The dump did not load completely" when another table used an extension, a type or a function of the dump. These objects now stay as they were, and the import is a success. The import sheet then stays open and names them.
- **The right number of tables in the import sheet.** For a file of pg_dump -Fc the sheet counted each table of the database as a table that stays.
