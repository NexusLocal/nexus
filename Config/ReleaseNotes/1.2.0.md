# Nexus 1.2.0: move from Local

## 🚚 Move from Local

Nexus finds Local by WP Engine (earlier Local by Flywheel) on your Mac. Click "Move from Local…" on the Overview. The sheet shows each site first, and you choose what moves.

- **Sites.** Each WordPress site keeps its folder in `~/Local Sites` and its name, for example `blog.local`. Nexus serves it over HTTPS with the same PHP version and web server, nginx or Apache. An old PHP gets PHP 8.2. Your own nginx lines and `php.ini` lines move too.
- **Databases.** Nexus copies the database of each site. A site that runs in Local gives the data of this moment. For a stopped site, Nexus opens a copy of its data folder, so Local can stay closed. MySQL 5.7 goes to MySQL 8.0.
- **WordPress settings.** `wp-config.php` gets the database of Nexus, and the URLs change from `http://` to `https://`, also for each site of a network. Nexus keeps a copy of each file that it changes.
- **One step for you.** Click "Quit Local" when the sheet asks for it. Then Nexus takes over ports 80 and 443 and opens each site once.
- **The certificates of Local.** The last sheet offers to remove the trust of each Local certificate, because its key is a plain file.
- **Nothing in Local changes.** The report tells you what moved and how to go back.
- **The command line.** `nexus import local` does the same.

## 🛠 Fixes

- **"Change the URLs" on a network on subdomains.** A change from `http://` to `https://` now changes each site of the network, not only the main site.
- **"Quit Herd" shows that Herd quits.** The banner shows "Quitting…" until Herd has stopped.
