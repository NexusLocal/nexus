# Nexus 0.2.5: PCOV for Pest TIA and mutation tests

## 🛠 Fixes and small changes

- PCOV now also turns on for `pest --tia` and `pest --mutate`. In 0.2.4, `pest --tia` ran every test, because it had no code coverage.
- The Packages screen shows "Mailpit" with its version, as it does for Composer and WP-CLI.
- Nexus checks for app updates every hour, not once a day. An update still installs only when you quit Nexus.
