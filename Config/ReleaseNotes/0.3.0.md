# Nexus 0.3.0: Nexus for coding agents

## 🤖 Your coding agent uses Nexus

Claude Code, Codex, Cursor and other coding agents can now use Nexus in each project. Turn them on in the new Settings > Agents. An agent then knows the URL, the database, the logs and the mail of the project. It does not start its own web server. It does not guess a port or a password.

- **Mail from start to end.** An agent fills in a sign-up form, waits for the mail and opens the link or reads the code in it. Mail never leaves your Mac.
- **Errors first.** When a page fails, the agent reads the newest errors of the site: the Laravel log, the PHP errors and the requests that failed.
- **Workspaces.** In a git worktree, the agent uses the URL and the database of that workspace.
- **You decide what agents can do.** "Agents can" has three levels: only look, look and set up (the default), or also remove. No agent can delete a database or your files. A removed workspace keeps a copy of its database for 7 days.
- **Fewer questions.** Claude Code and Codex look at your sites, logs and mail without a question. They still ask before each change. Turn on "Ask me before agents look" to get a question each time.

Nexus adds one entry `nexus` to the settings of each agent that you turn on. Nexus supports Claude, Claude Code, Codex, Cursor, Gemini CLI, Junie, OpenCode, VS Code, Windsurf and Zed. "Add agent…" > "Other agent…" shows the entry for another agent. In the terminal, `nexus mcp install`, `nexus mcp status` and `nexus mcp uninstall` do the same.

## 🧪 A safe database for your tests

A test that resets the database removes all the data in it. When the tests of a Laravel site use your development database, the Site screen now warns you. "Choose test database…" makes a separate test database, switches the tests to SQLite in memory or keeps it as it is. Nexus writes only `.env.testing`, keeps a backup of an existing one and shows each line before it changes something. Agents get the same warning.

## 🛠 And more

- `nexus site info`, `nexus errors`, `nexus mail wait` and `nexus mail links` give you the same help in the terminal.
- The activity log names the agent of each change that an agent makes through Nexus.
