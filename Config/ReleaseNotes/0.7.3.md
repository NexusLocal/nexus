# Nexus 0.7.3: PostGIS, pgRouting and the mongodb extension

## 🗺 PostGIS and pgRouting

PostgreSQL 15 to 19 have PostGIS 3.7 and pgRouting 4.0. PostGIS has topology and vector tiles, and no raster. The package update comes by itself. Then run `CREATE EXTENSION postgis` or `CREATE EXTENSION pgrouting CASCADE` in your database.

## 🧩 mongodb for PHP

PHP 8.2 to 8.5 get the extension **mongodb** with their next package update. `mongodb/laravel-mongodb` needs it. It connects to your own MongoDB server or to MongoDB Atlas. It is off until you turn it on. A MongoDB server in Nexus comes later.

## 🛠 Fixes

- **A workspace that shares MongoDB now says so.** Nexus cannot copy a MongoDB database yet. A Laravel site with a MongoDB connection gets a workspace that is not isolated, unless a workspace key of the site gives that connection its own server or database. Before, this happened only for the default connection. A Node.js app with MongoDB gets a warning on its workspace.
