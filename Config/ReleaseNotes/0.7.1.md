# Nexus 0.7.1: PostgreSQL 19 and fixes for Next.js and crashes

## 🐘 PostgreSQL 19

PostgreSQL 19 is on the Packages screen.

## 🛠 Fixes

- **Next.js Server Actions work.** A form with a Server Action failed with "Invalid Server Actions request". Nexus now gives the origin of the app only to the dev files of Next.js. The pages keep the origin of the browser.
- **Apache shows no PHP source.** A request for a PHP file with capitals in its extension, such as `info.PHP`, showed the source of the file. It now gets the same refusal as on nginx.
- **A crash of a service is no longer a crash of Nexus.** When MariaDB or PHP crashed, Nexus sent a crash report under its own name and then stopped its crash reports. A later crash of such a service could also hang. Each service now crashes as a normal program.
- Sentry 9.35.0 for the crash reports and Swift Crypto 5.1.2.
