# Nexus 0.4.1: agents, updates and mail

## 🤖 A screen for your coding agents

The new Agents screen under Tools shows each coding agent that Nexus knows. Turn an agent on or off, choose what agents can do, and copy the entry for another agent. The screen also lists each MCP tool of Nexus with what it does. These settings were in Settings > Agents before.

## 🔄 Check for updates shows its result

"Check for updates" on the Packages screen now says what it found: all packages are up to date, or the updates that Nexus installs. The Mail screen and each service screen show the same result. The switches for the automatic package updates are on the Packages screen now.

## ✉️ Mail

- **Each mail gets the tag of its site.** A Laravel site can send its mail to Nexus with another SMTP user name. Nexus now sets the user name to the host of the site by itself. "Show mails" then finds the mails of that site. The old values stay in the .env as comment lines. After "Use the old mail settings…" Nexus does not change the user name again.
- **Open in Mailpit** on the Site screen opens Mailpit with the mails of that site.
- **Dark mails.** Settings > Mail has "Appearance of mails inside Nexus": Light, Dark or Auto. Auto follows your Mac.

## 🛠 And more

- Redis has a redis.conf that belongs to you, as MySQL has my.cnf. Open it on the Redis screen. Nexus keeps the port, the address, the data folder and the number of databases.
- "Add Nexus to PATH" is on the Command line screen now.
- The Tools in the sidebar are in alphabetical order.
