# Nexus 1.1.0: PHP 8.6

## 🐘 PHP 8.6

- **PHP 8.6 with all extensions.** Install it on the Packages screen or with `nexus install php 8.6`. It has the same extensions as PHP 8.2 to 8.5, also Xdebug, Redis, pcov, Imagick and MongoDB.
- **A locked switch for an extension that is not there yet.** When the package of a PHP version does not have an extension, its switch is off and locked. A click on its name tells you why. A package update adds the extension later, and then the switch works.
- **The newest PHP in the New site sheet.** The sheet offers to install the newest PHP, not a fixed PHP 8.5. The messages of the `nexus` command name it too.

## 🔒 igbinary

PHP 8.2 to 8.6 get the newest igbinary with their next package update. It limits how deep `igbinary_unserialize` goes, and it guards against a stack overflow on deeply nested data.
