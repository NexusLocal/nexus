# Nexus 0.4.0: see your dumps

## 🐞 Each dump() and dd() in one place

Nexus now catches `dump()` and `dd()` of each PHP site and workspace, without a change in your code. The new Dumps screen under Tools shows them for each request and each command. A dump shows as a tree that opens and closes.

- **API answers stay valid.** With "Normal pages only" a page in your browser still shows each dump. An API answer or an update of Livewire, Inertia, htmx or Turbo stays clean. Its dumps show only in Nexus. `dd()` always shows on the page, because it stops the request.
- **Commands too.** The dumps of `php artisan`, queue workers and other PHP commands also show in Nexus. The terminal still shows each dump.
- **From the dump to the code.** A click on the file of a dump opens your code editor at that line. The copy button copies the text of the dump.
- **Remove what you do not need.** Remove one dump, one request or all dumps of a site.
- **Clear warnings.** When a site blocks Nexus, for example with `VAR_DUMPER_FORMAT` in its `.env`, the screen says so and opens the file.

## 🌐 Your dumps in the browser

"Open in Browser" opens a web page of Nexus with the same list and tree, as "Open in Mailpit" does for mail. The page updates live while your site runs. It can also remove and clear dumps. The page is only on your Mac (127.0.0.1), and other websites cannot read it.

## 🛠 And more

- `nexus dumps` shows the newest dumps in the terminal. Add `--follow` to see each new dump, `--site` for one site, or `--json` for a script. `nexus dumps open` opens the web page.
- The About window shows the licenses of the software that Nexus includes.
