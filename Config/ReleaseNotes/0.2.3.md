# Nexus 0.2.3: package updates without a click

## 📦 Package updates install by themselves

Nexus now installs the updates of your packages automatically, for example a security fix of PHP or Node.js. An update stays in the same version line: PHP 8.4 stays PHP 8.4. Nexus checks at launch and once a day, keeps the data of each service and restarts the service after the update.

You can turn this off in Settings > Updates > Packages. If you turned the setting off before, it stays off.
