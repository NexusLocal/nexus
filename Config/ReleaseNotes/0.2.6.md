# Nexus 0.2.6: updates while Nexus runs

## 🔄 Automatic updates that install

Settings > Updates has the new switch "Install updates automatically". With it on, Nexus downloads an update by itself and then asks you to restart. Before this version, an update waited until you quit Nexus. Most people seldom do that. Nexus asks again one hour after "Not now". When you quit Nexus, the update installs too.

With the switch off, Nexus shows the update window as soon as it finds an update. Nexus checks every hour.
